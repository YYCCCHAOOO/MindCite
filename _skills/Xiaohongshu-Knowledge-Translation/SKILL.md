# Xiaohongshu Knowledge Translation

## 触发条件

- `生成小红书笔记`
- `把这个理论整理成小红书`
- `把分类综述转成小红书草稿`

## 输入范围

- 优先使用已审核的分类综述笔记。
- 可辅助使用对应精读 notes，但必须标明来源。

## 强制规则

- 不自动发布。
- 不把未经审核的单篇论文结论包装成确定性建议。
- 不提供投资建议。
- 不夸大论文贡献、政策含义或因果关系。
- 默认输出草稿，不改动原始 notes。

## 第一版工作流

1. 读取已审核分类综述。
2. 提炼一个适合公众理解的主题。
3. 写成“问题意识 + 核心解释 + 文献路线 + 我的研究启发”的草稿。
4. 保留内部参考文献清单，方便回查。

## 草稿类型

- 理论地图
- 方法入门
- 论文阅读路线
- 研究选题灵感
