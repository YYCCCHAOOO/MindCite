# Notice and Acknowledgements

MindCite is an independently implemented public research-workflow template. Some workflow ideas were inspired by public Codex skill repositories created by GitHub user `cheneternity`:

- `cheneternity/Zotero-Analytical-Workflow-Skills`: Zotero-to-Obsidian reading workflow ideas, including separating batch management, data extraction, and note writing.
- `cheneternity/Research-Vault-Literature-Retrieval`: Vault-based literature retrieval ideas, especially the principle of answering from existing local notes rather than external memory.

MindCite does not vendor, copy, or redistribute files from those repositories. The public implementation in this repository uses its own structure, scripts, configuration layer, data contracts, demo data, safety checks, and documentation.

At the time of the attribution review on 2026-05-07, the upstream repositories did not contain a root `LICENSE`, `NOTICE`, or `COPYING` file. For that reason, MindCite treats those repositories as conceptual inspiration only. Do not copy upstream source text, templates, or files into MindCite unless the upstream author grants permission or adds a compatible license.

If you are the upstream author and would like the attribution wording changed, please open an issue or contact the maintainer.
